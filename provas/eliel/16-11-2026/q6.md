# Questão 6 – Qual será a saída?
Observe o código e responda qual será o resultado exibido.

```c
#include <stdio.h>

int main() {
    int x = 5;

    if (x > 3) {
        printf("Maior que 3");
    } else {
        printf("Menor ou igual a 3");
    }

    return 0;
}
```

# Resposta:

```
Maior que 3
```
